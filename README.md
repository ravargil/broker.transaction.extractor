# Broker Transaction Extractor

## Overview
The Broker Transaction Extractor is a Python application designed to parse broker statements and extract trade transactions. The extracted data can then be added to a Google Sheet for easy tracking and analysis.

## Setup Instructions
1. Clone the repository to your local machine:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd broker.transaction.extractor
   ```
3. Install the required Python packages:
   ```
   pip install -r requirements.txt
   ```

## Usage
To run the application, execute the following command:
```
python main.py
```
This will start the application and display a greeting message.
